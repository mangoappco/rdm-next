Accent pairs

Primary para lo mas importante (FAB, acciones), secondary para lo medio (chips, dismiss), tertiary para enfasis especial (badges), error para urgencia. Error es estatico: no cambia con dynamic color.

Outline

Rules

Los pares garantizan 3:1 minimo; texto e iconos dentro de un target piden 4.5:1. Container nunca para texto. Otros roles sirven si container y texto dan 3:1 (habilita el destructivo con error). El vendor trae ademas background y on-background de M2: no son spec actual.
