Layout

M3 no exporta tokens de layout ni spacing en el vendor, asi que el container es extension del proyecto (--rdm-layout-*). Esta pagina vive dentro de uno: redimensiona la ventana y los margenes laterales cambian de 16px a 24px al cruzar los 600px.

Breakpoints

5 breakpoints oficiales (la spec los llamaba window size classes hasta mayo 2026). El container solo aplica el margen; las columnas se definiran cuando un componente las necesite.

Scaffold

El scaffold estructura cada pieza del layout en bars, rails y panes. Sin CSS todavia: se publica el vocabulario para que los componentes lo consuman.

PiezaDefinicion
BarEnmarca la pagina: app bar y navegacion inferior
RailPerimetro alrededor de los panes: navegacion y toolbars
PaneContenido principal; se adapta al breakpoint

Grid

8 columnas; cada pane ocupa 4 (alt del diagrama oficial). Dato de spec, sin CSS: ningun componente necesita columnas todavia (YAGNI).

Margin

El espacio entre el borde de la pantalla y los elementos (definicion oficial). Aca vive en --rdm-layout-margin: 16px en compact, 24px desde medium (600px).

Measure

La spec pide 40-60 caracteres por linea en texto de lectura. Medido con Google Sans contando el wrap real: el showroom es texto de UI, no lectura, pero el copy largo de mango-next si cae en esta regla.

Container

Ancho maximo de --rdm-layout-max-width: 600px (decision del proyecto: piso de medium 600-839, numero publicado; la spec no publica max-width de contenido), centrado con margin-inline: auto y aire lateral de --rdm-layout-margin. Requiere el reset box-sizing: border-box de base.css: sin el, width: 100% mas padding desborda.

Este bloque es un .rdm-container real anidado: el padding-inline se suma al de la pagina, y el doble aire lateral es el margen en accion (16px, 24px desde 600px).
